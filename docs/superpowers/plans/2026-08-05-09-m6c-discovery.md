# M6c — Discovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `/` becomes the discovery home feed, the track table moves to `/pool`, and members get browsable pages — spec §7 of `docs/superpowers/specs/2026-07-29-m6-org-layer-design.md`.

**Architecture:** Server-rendered pages calling three new definer RPCs (`feed_tracks`, `feed_new_crates`, `member_resolve`) plus the existing `pool_list`/`crate_list`. Feed signal ranking aggregates likes/plays/downloads **by track** (`files.track_id`), so the 72 already-merged duplicates pool their signals — this supersedes spec §3's per-file fold, which matched a merge design M4 did not build (files survive merges under the winner track; nothing needs moving).

**Tech Stack:** Astro SSR pages, Postgres definer RPCs, pgTAP.

## Global Constraints

- Revoke-first grants on any new object; definer RPCs `set search_path = ''`, `revoke execute from public, anon`, `grant execute to authenticated`; membership gate via `is_active_member() or is_owner()` exactly as `pool_list` (migration 28) does.
- Anonymity invariant (spec §5): no RPC returns another member's identity for a like or play — feed rows carry counts only.
- Feed windows: fixed 7 days (owner decision 2026-07-29). Sections and order, spec §7: Fresh, Hot this week (plays+likes 7d, downloads tiebreak), New public crates (`made_public_at desc`), Most liked all-time.
- Member page hides private crates entirely — no count, no hint (owner decision).
- Empty feed sections render an honest empty state; they do not hide.
- Migrations: new file `supabase/migrations/20260805100000_31_feed.sql`, never edit applied ones. pgTAP: one `plan()` per file, 4-arg `throws_ok`.
- No new islands; brutalist server-rendered idiom. Any new form/link JS must respect the ClientRouter rules (capture-phase delegation / `data-astro-reload`) documented at the top of `src/scripts/site.ts`.
- MIT/AGPL header on every new source file.
- Deploy order: migration before `npm run deploy`.

`supabase/migrations/20260805100000_31_feed.sql` — MIT/AGPL header, then:

```sql
-- feed_tracks: one definer gate, three sections. Ranking aggregates by
-- files.track_id so merged duplicates pool their signal (72 merges live
-- on hosted as of 2026-08-05). One row per track: preferred_file_id if it
-- is a stored pool row, else the track's newest stored file.
create or replace function public.feed_tracks(p_section text, p_limit int default 12)
returns setof public.pool_tracks
language plpgsql security definer set search_path = '' as $$
begin
  if not (public.is_active_member() or public.is_owner()) then
    raise exception 'not a member' using errcode = '42501';
  end if;
  if p_section = 'fresh' then
    return query
      select t.* from public.pool_tracks t
       where t.created_at > now() - interval '7 days'
       order by t.created_at desc limit p_limit;
  elsif p_section in ('hot', 'top') then
    return query
      with sig as (
        select f.track_id,
               coalesce(sum(case when p_section = 'hot' then
                 (select count(*) from public.play_events pe
                   where pe.file_id = f.id
                     and pe.played_at > now() - interval '7 days')
               + (select count(*) from public.likes l
                   where l.file_id = f.id
                     and l.created_at > now() - interval '7 days')
                 else (select count(*) from public.likes l where l.file_id = f.id)
               end), 0) as score,
               coalesce(sum((select ts.download_count from public.track_stats ts
                             where ts.file_id = f.id)), 0) as tiebreak
          from public.files f
         where f.state = any (public.pool_visible_states()) and f.track_id is not null
         group by f.track_id
         having coalesce(sum(case when p_section = 'hot' then
                 (select count(*) from public.play_events pe
                   where pe.file_id = f.id
                     and pe.played_at > now() - interval '7 days')
               + (select count(*) from public.likes l
                   where l.file_id = f.id
                     and l.created_at > now() - interval '7 days')
                 else (select count(*) from public.likes l where l.file_id = f.id)
               end), 0) > 0
      ),
      face as (
        select s.track_id, s.score, s.tiebreak,
               coalesce(
                 (select tr.preferred_file_id from public.tracks tr
                   where tr.id = s.track_id
                     and exists (select 1 from public.pool_tracks pt
                                  where pt.file_id = tr.preferred_file_id)),
                 (select pt.file_id from public.pool_tracks pt
                   join public.files ff on ff.id = pt.file_id
                  where ff.track_id = s.track_id
                  order by pt.created_at desc limit 1)
               ) as file_id
          from sig s
      )
      select t.* from face fc
        join public.pool_tracks t on t.file_id = fc.file_id
       where fc.file_id is not null
       order by fc.score desc, fc.tiebreak desc, t.created_at desc
       limit p_limit;
  else
    raise exception 'unknown feed section %', p_section using errcode = '22023';
  end if;
end $$;
revoke execute on function public.feed_tracks(text, int) from public, anon;
grant execute on function public.feed_tracks(text, int) to authenticated;
```

`feed_new_crates` and `member_resolve` follow the same gate/revoke/grant shell:

```sql
create or replace function public.feed_new_crates(p_limit int default 8)
returns table (id uuid, name text, owner_name text, track_count bigint,
               total_duration_ms bigint, made_public_at timestamptz)
language plpgsql security definer set search_path = '' as $$
begin
  if not (public.is_active_member() or public.is_owner()) then
    raise exception 'not a member' using errcode = '42501';
  end if;
  return query
    select c.id, c.name,
           coalesce(m.username, split_part(m.email, '@', 1)) as owner_name,
           count(ci.file_id) filter (where f.state = any (public.pool_visible_states())) as track_count,
           coalesce(sum(f.duration_ms) filter (where f.state = any (public.pool_visible_states())), 0)::bigint,
           c.made_public_at
      from public.crates c
      join public.members m on m.user_id = c.owner_id
      left join public.crate_items ci on ci.crate_id = c.id
      left join public.files f on f.id = ci.file_id
     where c.is_public
     group by c.id, c.name, m.username, m.email, c.made_public_at
     order by c.made_public_at desc nulls last
     limit p_limit;
end $$;

create or replace function public.member_resolve(p_username text)
returns table (user_id uuid, username text, joined_at timestamptz, track_count bigint)
language plpgsql security definer set search_path = '' as $$
begin
  if not (public.is_active_member() or public.is_owner()) then
    raise exception 'not a member' using errcode = '42501';
  end if;
  return query
    select m.user_id, m.username, m.created_at,
           (select count(distinct fc.file_id) from public.file_claims fc
             join public.files f on f.id = fc.file_id
            where fc.user_id = m.user_id
              and f.state = any (public.pool_visible_states()))
      from public.members m
     where m.username = p_username and m.revoked_at is null;
  if not found then
    raise exception 'no such member' using errcode = 'P0002';
  end if;
end $$;
```
