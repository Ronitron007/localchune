# Milestone 5 — Pool UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The pool becomes usable. A member opens `/`, sees every analysed track in the pool, filters it by text / BPM / key / quality / uploader, sorts it, plays a track from a single persistent player bar, downloads the original, and opens a per-track detail page. The upload page grows a live state ticker so a finished upload visibly completes its journey.

**Spec:** [`docs/superpowers/specs/2026-07-28-ui-components.md`](../specs/2026-07-28-ui-components.md) §1–§5, plus the two §6 additions (`FileStateTicker`, `AnalysisFailedRow`). Everything the spec assigns to M4, M6, M7 or M8 is out of scope except where it says *"design the slot, ship it empty"* — that means `GenreFacet` (§2) and the M4/M7 sections of the track detail page (§5).

**Architecture:** All filtering, sorting and paging happens in Postgres, behind **one** list RPC. Astro server-renders the first page of results — so a filtered URL is shareable *and* server-rendered — and hands them to **one** Solid island, which refetches the same RPC through **one** JSON API route when a filter changes or the reader asks for more. Playback is a module-scope store shared by two islands; the browser talks to R2 directly over short-lived signed GETs, never through the Worker.

**Tech stack:** unchanged — Astro 7 SSR + Solid islands on `@astrojs/cloudflare`, Supabase (Postgres 15 + Auth), R2 via `aws4fetch`, Vitest (node), pgTAP.

## Prerequisites

M5 reads two things M3 owns. Neither is forked here.

1. **`public.audio_analysis` must exist.** It is created by M3 Task 9, Step 1. As of writing, M3 Tasks 1–8 are done and Task 9 is not. Land M3 Task 9's migration **first**, as `supabase/migrations/20260728110000_09_analysis.sql`, so a `db reset` applies it before M5's migrations. M5 does not create the table and does not copy its DDL.

2. **M3 Task 9's `persist()` must write three artifact keys.** The draft migration in `2026-07-27-03-analysis-worker.md` has **no `preview_key` / `peaks_key` / `artwork_key` columns**, yet `workers/analysis/src/index.ts` already puts those objects at `derived/<file_id>/<name>`. Nothing records the name, so nothing can ever find them again. M5 Task 2 adds the three columns (`alter table ... add column if not exists`, so it is safe whichever milestone lands first); **M3 Task 9 must populate them.** Until it does, the player falls back to streaming the original file and the waveform renders flat — both handled, neither an error.

Two smaller gaps in the same draft, recorded here so they are not lost:

- The draft enables RLS on `audio_analysis` and grants **nothing**. With RLS on, no policy and no base grant, `authenticated` cannot read it at all and every join returns "permission denied for table". M5 Task 2 adds the policy and the grants (grants are idempotent, so duplicating them in M3 is harmless).
- There is no `bpm_confidence` column, although PRD §4 lists one on `tracks`. M5 does not need it: a degraded analysis is detected as `bpm is null or bpm <= 0`. Add the column in M3 when the container starts reporting it.

**Until M3 Task 9 runs, the pool is empty and that is correct.** `pool_list()` returns files in state `stored`, and only the analysis worker moves a file there. A track with no BPM and no key is not a usable pool entry.

## Global Constraints

Each of these is a bug that has already been paid for once. Violating one reintroduces it.

- **Astro SSR + Solid islands.** `client:load`, islands leaf-level and small, one island per interactive region. `jsxImportSource` is `solid-js`. No React idiom — no `useState`, no `useEffect`, no `key` props, no `className`. Props are getters: destructuring a Solid props object breaks reactivity.
- **`Astro.locals.supabase` is the request's Supabase client.** Never construct a second one. A second client's `getAll` re-reads the original `Cookie` header and misses a token rotation the middleware just performed (`src/middleware.ts`).
- **Islands cannot talk to Supabase.** Auth cookies are `httpOnly`. Every island fetches a JSON API route under `src/pages/api/`.
- **Every API failure response is JSON `{error}` with `content-type: application/json`.** A non-JSON body means "your session is gone" to `src/lib/uploader.ts`, and the same convention now covers the pool routes. Reuse `jsonError` / `rpcError` / `dbErrorResponse` from `src/lib/upload-api.ts`.
- **Astro 5+ CSRF origin check:** an unsafe-method fetch needs `content-type: application/json`, and so does a `curl` reproduction. **M5 adds no unsafe-method routes** — every route it adds is a `GET`. Keep it that way; the moment a POST appears, it needs the header.
- **RLS and base grants.** Any new view, function or table needs explicit grants to `authenticated`. Functions are `security definer` + `set search_path = ''` + `revoke execute from public, anon` + `grant execute to authenticated`. **No RLS policy on table X may `SELECT FROM` table X** (42P17). pgTAP uses the 4-argument `throws_ok`, inserts into `public.allowlist` **before** `auth.users` (the `handle_new_user` trigger aborts otherwise, and it provisions `public.members` itself — never insert members by hand), and has exactly one `plan()` per file.
- **Vitest runs in the node environment. No jsdom.** Pure logic is unit-tested. Browser behaviour — real audio playback, canvas pixels, drag, `IntersectionObserver` — is a **manual check** in Task 8's checklist, never a stubbed-green test. The player store is unit-tested through an injected fake audio element; that tests the *state machine*, and the plan says so, because a passing store test is not evidence that a track plays.
- **MIT header on every hand-authored file.** Copy the three-line block from `src/lib/email.ts`. `.astro` files carry it inside the frontmatter fence; `.sql` migrations use `--` comments. The pgTAP fixtures under `supabase/tests/` carry none today, and the new ones match the existing files rather than diverging.
- **R2 GETs are signed by the existing signer in `src/lib/r2.ts`** (`objectUrl` + `aws4fetch`). Task 7 adds one function, `presignGet`, next to `presignPut`; it does not build a second signer and does not import `aws4fetch` anywhere else. **The Worker never proxies audio bytes** (PRD §12) — it returns a URL and the browser fetches R2 directly.
- **Degraded analysis is data, not an error.** `bpm is null or bpm <= 0` renders `—` with a tooltip reading "no beat detected", never a red state. The same for a missing key, a missing tier and a missing duration.
- **`raw_tags` is the title/artist source until M7.** Tags are frequently absent or junk. The filename fallback lives in SQL (`display_artist()` / `display_title()`), because server-side search and sort need the same strings the table renders — deriving them twice would let search and display disagree.

## Decisions

These were settled before the plan was written. They are recorded because each one closes off an obvious-looking alternative.

**One list endpoint, one view, two RPCs.** `GET /api/pool` is the only list endpoint; every filter is a query parameter and every filter runs in Postgres. Behind it, `public.pool_tracks` is an ungranted view that owns the join and every derived column, and `public.pool_list()` / `public.pool_get()` are `security definer` functions that own the visibility gate and the filters. The view is deliberately **not** `security_invoker` and is granted to **no role at all** — the same idiom as `ingest_set_state()` in migration 07, which is granted to nobody and reachable only from its callers. Making it `security_invoker = true` and granting it directly looks safer but is not: `members` RLS would then hide every other member's row, so the uploader column would silently render blank for every track but your own. `member_storage()` in migration 08 already documents this exact trade-off.

**Every sort is an ascending scan over a precomputed text key.** The view exposes six `sk_*` columns, all `collate "C"`, all constructed so that ascending order is the order the reader asked for — a descending sort like "newest first" is encoded by subtracting from a constant, not by flipping the `ORDER BY`. Consequences: one cursor format, one keyset predicate `(sk, file_id) > (cursor_sk, cursor_id)`, no `NULLS FIRST/LAST` reasoning anywhere (unknown values map to a high sentinel string), and no dynamic SQL. The cursor is the row's `sk || file_id::text`; because the id is always the last 36 characters, it parses without a separator and no artist name can corrupt it.

**No virtualiser.** The spec asks for virtualised rows. A page is 100 rows, "load more" appends another 100, and the pool is ~2k tracks. A windowing library is a dependency, a scroll-position bug and a keyboard-navigation bug bought to solve a problem that starts at ~5k DOM rows. **Trip-wire:** if a single view ever renders more than 1000 rows, revisit this. Recorded in the code as a comment, not just here.

**The first page is server-rendered.** `src/pages/index.astro` calls `pool_list()` with the filters from its own URL and passes the rows into the island as props. This kills the fetch waterfall on first paint, makes a filtered URL genuinely shareable rather than just re-derivable, and lets the three `EmptyState` variants be decided on the server where "is the pool empty at all" is already known.

**One player, two islands, one module-scope store.** `src/lib/player-store.ts` holds module-scope Solid signals and the single lazily-created `Audio` element. `PlayButton` (inside `TrackTable`) calls `playTrack()`; `PlayerBar` reads the signals. This works because Vite emits one shared chunk for a module both islands import — both islands must import the same path. The same mechanism carries the current batch id from `UploadDropzone` to `FileStateTicker` in Task 8, so there is one pattern in the codebase, not two.

**Uploader attribution is the email local part, not the email.** `pool_list()` returns `uploader_name = split_part(email, '@', 1)` and the `uploaded_by` uuid. Ten people who know each other do not need each other's addresses printed on 2000 rows; `/admin` remains the only place a full email appears.

**Crates and genre ship as slots.** `GenreFacet.tsx` exists and renders nothing while its `families` prop is empty (always, until M8). The `TrackRow` has no crates column and `AppNav` has no Crates link — the spec's "omit, don't disable" rule applied to a milestone that has not happened.

```ts
// src/lib/track-format.ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

/**
 * Pure formatting and Camelot maths, shared by every track-rendering
 * component. No DOM, no fetch — so it is unit-testable under Vitest's node
 * environment, which is the only environment this repo has.
 *
 * `formatDuration` lives in ./preflight and `formatBytes` in ./format.
 * Import them; do not add a third copy here.
 */

export type Camelot = { num: number; letter: 'A' | 'B' }

/** Sorts after every real key. 12B is 121, so anything above that will do. */
export const UNKNOWN_SORT_KEY = 999

/**
 * Above this coefficient of variation the beat grid is not a constant
 * tempo, and the displayed BPM is an average rather than a fact. PRD 4
 * names 0.02.
 */
export const CONSTANT_TEMPO_CV = 0.02

const CAMELOT_RE = /^([1-9]|1[0-2])([AB])$/

export function parseCamelot(key: string | null | undefined): Camelot | null {
  if (typeof key !== 'string') return null
  const m = CAMELOT_RE.exec(key.trim().toUpperCase())
  if (m === null) return null
  return { num: Number(m[1]), letter: m[2] as 'A' | 'B' }
}

/**
 * The cue-tracks composite-sort trick (`FileList.tsx:120-125`). Camelot keys
 * sort wrong lexicographically — '10A' lands before '2A' — in every naive
 * implementation. Mirrored by `camelot_sort` in migration 10 so the client
 * and the server agree on the order.
 */
export function camelotSortKey(key: string | null | undefined): number {
  const c = parseCamelot(key)
  if (c === null) return UNKNOWN_SORT_KEY
  return c.num * 10 + (c.letter === 'B' ? 1 : 0)
}

/**
 * The harmonically compatible neighbours of a key: one step either way
 * around the wheel in the same mode, plus the relative major/minor. Order is
 * self, +1, -1, relative — stable, so the KeyFilter can render the chip set
 * without re-sorting. The server computes the same set in
 * `public.camelot_neighbours()`; this copy exists so the filter can SHOW
 * which keys it is about to include.
 */
export function harmonicKeys(key: string | null | undefined): string[] {
  const c = parseCamelot(key)
  if (c === null) return []
  const up = (c.num % 12) + 1
  const down = ((c.num + 10) % 12) + 1
  const other = c.letter === 'A' ? 'B' : 'A'
  return [`${c.num}${c.letter}`, `${up}${c.letter}`, `${down}${c.letter}`, `${c.num}${other}`]
}

/**
 * One decimal, '~' when the tempo drifts, em dash when there is no beat.
 * A degraded analysis (bpm 0) is data: the worker listened and found no
 * pulse. It is never rendered as an error state.
 */
export function formatBpm(
  bpm: number | null | undefined, ibiStdMs: number | null | undefined,
): string {
  if (typeof bpm !== 'number' || !Number.isFinite(bpm) || bpm <= 0) return '—'
  const drifts =
    typeof ibiStdMs === 'number' && Number.isFinite(ibiStdMs) && ibiStdMs > 0 &&
    (ibiStdMs * bpm) / 60_000 >= CONSTANT_TEMPO_CV
  return `${drifts ? '~' : ''}${bpm.toFixed(1)}`
}

const MUSICAL_LONG: Record<string, string> = { m: ' minor', M: ' major' }

export function keyTooltip(
  camelot: string | null, open: string | null, musical: string | null,
): string {
  if (!camelot) return 'no key detected'
  const parts = [`Camelot ${camelot}`]
  if (open) parts.push(`Open Key ${open}`)
  if (musical) {
    // 'Am' -> 'A minor', 'C#M' -> 'C# major', anything else passed through.
    const tail = musical.slice(-1)
    const long = MUSICAL_LONG[tail]
    parts.push(long === undefined ? musical : `${musical.slice(0, -1)}${long}`)
  }
  return parts.join(' · ')
}

export function qualityLabel(tier: number | null | undefined): string {
  return typeof tier === 'number' ? `Tier ${tier}` : '—'
}

/**
 * The tooltip must say MEASURED, and must name the measurement, because the
 * claim it is making is "your file is not what its container says". PRD 7.2:
 * `abstain` means the detector had nothing to work with — rendering that as
 * suspicion is how a clean rip gets called a fake.
 */
export function qualityTooltip(
  tier: number | null | undefined,
  lossyAncestor: string | null | undefined,
  measCutoffHz: number | null | undefined,
): string {
  if (typeof tier !== 'number') return 'not analysed yet'
  const cutoff =
    typeof measCutoffHz === 'number' && measCutoffHz > 0
      ? `measured cutoff ${(measCutoffHz / 1000).toFixed(1)} kHz`
      : null
  switch (lossyAncestor) {
    case 'suspected':
      return `Tier ${tier} · FLAC/WAV container, ${cutoff ?? 'no cutoff measured'} — transcode suspected`
    case 'confirmed':
      return `Tier ${tier} · ${cutoff ?? 'no cutoff measured'} — lossy ancestor confirmed`
    case 'abstain':
      return `Tier ${tier} · not enough signal to judge the source`
    case 'none':
      return cutoff === null ? `Tier ${tier}` : `Tier ${tier} · ${cutoff}, no transcode indicators`
    default:
      return `Tier ${tier}`
  }
```

```sql
-- First non-empty value among the given keys, in the order given.
-- `with ordinality` + `order by` is load-bearing: unnest() makes no promise
-- about row order, so a bare `limit 1` could return the wrong tag.
create or replace function public.tag_value(p_tags jsonb, variadic p_keys text[])
returns text language sql immutable set search_path = '' as $$
  select t.v
    from unnest(p_keys) with ordinality as k(name, ord)
    cross join lateral (select nullif(btrim(p_tags ->> k.name), '') as v) t
   where t.v is not null
   order by k.ord
   limit 1;
$$;

-- The harmonically compatible set: one step either way around the wheel in
-- the same mode, plus the relative major/minor. The modular arithmetic is
-- the whole reason Camelot notation exists -- 12 and 1 are ADJACENT, and an
-- implementation that treats the number as an ordinary integer silently
-- drops the wraparound and mixes badly at exactly one point on the wheel.
create or replace function public.camelot_neighbours(p_key text)
returns text[] language plpgsql immutable set search_path = '' as $$
declare
  v_key text := upper(btrim(coalesce(p_key, '')));
  v_num int;
  v_let text;
begin
  if v_key !~ '^([1-9]|1[0-2])[AB]$' then
    return null;
  end if;
  v_num := left(v_key, length(v_key) - 1)::int;
  v_let := right(v_key, 1);
  return array[
    v_num::text                     || v_let,
    ((v_num % 12) + 1)::text        || v_let,
    (((v_num + 10) % 12) + 1)::text || v_let,
    v_num::text                     || (case when v_let = 'A' then 'B' else 'A' end)
  ];
end $$;
revoke execute on function public.camelot_neighbours(text) from public, anon, authenticated;

-- The view.
--
-- SECURITY_INVOKER IS DELIBERATELY OFF and the view is granted to NO role.
-- It runs as its owner (postgres), which owns every underlying table and
-- therefore bypasses their RLS. That is safe only because nothing can reach
-- it: the visibility gate lives in the SECURITY DEFINER functions in Task 3,
-- exactly as migration 08's member_storage() documents for the same reason.
--
-- The alternative -- security_invoker = true, granted to authenticated --
-- looks safer and is worse. members' RLS ("members read own row") would then
-- hide every other member's row, so `uploader_name` would render blank for
-- every track except your own, with no error anywhere.

-- finding is accepted: a view with zero grants is unreachable by anon and
-- authenticated alike.
-- ============================================================

  -- one of these text columns, so there is one cursor format, one keyset
  -- predicate, and no NULLS FIRST/LAST reasoning anywhere: an unknown
  -- value maps to a high sentinel string and therefore sorts last.
  -- A descending sort is encoded by subtracting from a constant, not by
  -- flipping ORDER BY.

  -- COLLATE "C" on all six is not decoration. A CASE whose branches carry
  -- different collations raises 42P22 "could not determine which collation
  -- to use" -- at RUNTIME, from the CASE in pool_list() that picks one of
  -- these. Pinning all six to C also makes the keyset order byte-stable,
  -- which is what a cursor needs.
  -- ---------------------------------------------------------------
  ((lpad((99999999999999::bigint
          - (extract(epoch from f.created_at) * 1000)::bigint)::text, 14, '0')
   ) collate "C")                            as sk_added,
  ((case when a.bpm is null or a.bpm <= 0 then '99999999'
         else lpad(((a.bpm * 100)::int)::text, 8, '0') end) collate "C")
                                             as sk_bpm,
  ((lpad(d.camelot_sort::text, 3, '0')) collate "C")
                                             as sk_key,

  -- untitled upload lands at the end rather than at the top.
  ((lower(coalesce(d.display_artist, '~'))) collate "C")
                                             as sk_artist,
  ((case when coalesce(a.duration_ms, f.duration_ms, 0) <= 0 then '99999999'
         else lpad(coalesce(a.duration_ms, f.duration_ms)::text, 8, '0') end) collate "C")

    -- Lexicographic ordering puts '10A' before '2A'; this is the fix.
    -- Mirrored by camelotSortKey() in src/lib/track-format.ts.
    case when a.key_camelot ~ '^([1-9]|1[0-2])[AB]$'

              + (case when right(a.key_camelot, 1) = 'B' then 1 else 0 end)

) d;
```

```sql
-- supabase/migrations/20260728120100_11_pool_rpc.sql
-- localchune — MIT licensed. See LICENSE.
-- NOTE: the distributed combination is AGPL-3.0 because the analysis
-- worker includes Essentia. LICENSE explains why.

-- ============================================================
-- The one list endpoint, server-side in full.
--
-- SECURITY DEFINER because it reads public.pool_tracks, which bypasses RLS
-- (see migration 10). The gate is therefore the first statement in the body
-- plus `t.state = 'stored'` -- there is no second path in.
--
-- Numeric parameters are int / double precision rather than smallint / real
-- on purpose: PostgREST hands over JSON numbers, and int4 -> int2 is an
-- ASSIGNMENT cast, not an implicit one, so a smallint parameter makes
-- pool_list(p_tier_min => 4) fail function resolution outright.
--
-- Every reference inside the body is table-qualified. In a plpgsql
-- `returns table`, the output columns are variables, so a bare `bpm` would
-- be ambiguous against pool_tracks.bpm and raise 42702 at RUNTIME. Migration
-- 08 hit exactly this and renamed its outputs; qualification is the other
-- half of the same discipline.
-- ============================================================
create or replace function public.pool_list(
  p_q           text             default null,
  p_bpm_min     double precision default null,
  p_bpm_max     double precision default null,
  p_half_double boolean          default false,
  p_key         text             default null,
  p_harmonic    boolean          default false,
  p_tier_min    int              default null,
  p_uploader    uuid             default null,
  p_sort        text             default 'added_desc',
  p_cursor      text             default null,
  p_limit       int              default 100
)
returns table (
  file_id           uuid,
  track_id          uuid,
  uploaded_by       uuid,
  uploader_name     text,
  original_filename text,
  display_artist    text,
  display_title     text,
  container         text,
  byte_size         bigint,
  duration_ms       int,
  bpm               real,
  ibi_std_ms        real,
  key_camelot       text,
  key_open          text,
  key_musical       text,
  camelot_sort      int,
  quality_tier      smallint,
  lossy_ancestor    text,
  meas_cutoff_hz    int,
  integrated_lufs   real,
  has_preview       boolean,
  has_peaks         boolean,
  created_at        timestamptz,
  row_cursor        text
)
language plpgsql stable security definer set search_path = '' as $$
declare
  v_sort  text := coalesce(nullif(btrim(p_sort), ''), 'added_desc');
  v_limit int  := least(greatest(coalesce(p_limit, 100), 1), 200);
  v_q     text;
  v_lo    double precision;
  v_hi    double precision;
  v_keys  text[];
  v_ck    text;
  v_cid   uuid;
begin
  if not (public.is_active_member() or public.is_owner()) then
    raise exception 'forbidden' using errcode = '42501';
  end if;

  if v_sort not in ('added_desc','bpm_asc','key_asc','artist_asc','duration_asc','tier_desc') then
    raise exception 'unknown sort %', p_sort using errcode = '22023';
  end if;

  if p_key is not null and btrim(p_key) <> '' then
    if upper(btrim(p_key)) !~ '^([1-9]|1[0-2])[AB]$' then
      raise exception 'invalid camelot key %', p_key using errcode = '22023';
    end if;
    -- The harmonic expansion is computed HERE, not in the browser: a client
    -- that sends four keys instead of one is a client that can be wrong
    -- about the wraparound, and 12 <-> 1 is exactly where implementations
    -- get it wrong.
    v_keys := case when coalesce(p_harmonic, false)
                   then public.camelot_neighbours(p_key)
                   else array[upper(btrim(p_key))] end;
  end if;

  if p_q is not null and btrim(p_q) <> '' then
    -- Escape the LIKE metacharacters, backslash FIRST or the escapes get
    -- re-escaped. Someone searching for '100%' must not match every row.
    v_q := '%' || replace(replace(replace(btrim(p_q), '\', '\\'), '%', '\%'), '_', '\_') || '%';
  end if;

  if p_bpm_min is not null or p_bpm_max is not null then
    -- +/-3%, applied ONCE to the query bounds rather than per candidate.
    v_lo := coalesce(p_bpm_min, 0)    * 0.97;
    v_hi := coalesce(p_bpm_max, 1000) * 1.03;
  end if;

  if p_cursor is not null and length(p_cursor) > 36 then
    -- The uuid is always the last 36 characters, so the cursor needs no
    -- separator and no artist name can corrupt it.
    v_cid := right(p_cursor, 36)::uuid;
    v_ck  := left(p_cursor, length(p_cursor) - 36);
  end if;

  return query
  with base as (
    select t.*,
           (case v_sort
              when 'bpm_asc'      then t.sk_bpm
              when 'key_asc'      then t.sk_key
              when 'artist_asc'   then t.sk_artist
              when 'duration_asc' then t.sk_duration
              when 'tier_desc'    then t.sk_tier
              else                     t.sk_added
            end) as sk
      from public.pool_tracks t
     where t.state = 'stored'
       and (v_q is null
            or t.display_artist    ilike v_q escape '\'
            or t.display_title     ilike v_q escape '\'
            or t.original_filename ilike v_q escape '\')
       -- Half/double time. A 174 DnB track IS an 87 track to a DJ, and the
       -- pool is unusable without this. PRD 7 calls the octave problem a UX
       -- decision rather than a bug; this is the decision.
       and (v_lo is null
            or (t.bpm is not null and t.bpm > 0
                and ( (t.bpm between v_lo and v_hi)
                   or (coalesce(p_half_double, false) and (t.bpm * 2 between v_lo and v_hi))
                   or (coalesce(p_half_double, false) and (t.bpm / 2 between v_lo and v_hi)) )))
       and (v_keys is null or t.key_camelot = any (v_keys))
       and (p_tier_min is null or t.quality_tier >= p_tier_min)
       and (p_uploader is null or t.uploaded_by = p_uploader)
  )
  select b.file_id, b.track_id, b.uploaded_by, b.uploader_name,
         b.original_filename, b.display_artist, b.display_title,
         b.container, b.byte_size, b.duration_ms,
         b.bpm, b.ibi_std_ms,
         b.key_camelot, b.key_open, b.key_musical, b.camelot_sort,
         b.quality_tier, b.lossy_ancestor, b.meas_cutoff_hz, b.integrated_lufs,
         b.preview_key is not null, b.peaks_key is not null,
         b.created_at,
         (b.sk || b.file_id::text)
    from base b
   -- Keyset, never OFFSET: an upload landing mid-scroll would shift every
   -- later page by one row and silently hide a track. `collate "C"` on v_ck
   -- is required -- b.sk carries a declared C collation and the variable
   -- does not, and two differing implicit collations raise 42P22.
   where v_ck is null or (b.sk, b.file_id) > (v_ck collate "C", v_cid)
   order by b.sk, b.file_id
   limit v_limit;
end $$;
```

```ts
  'added_desc', 'bpm_asc', 'key_asc', 'artist_asc', 'duration_asc', 'tier_desc',

export type PoolSort = (typeof POOL_SORTS)[number]

export const PAGE_SIZE = 100
const MAX_Q_LENGTH = 120
const MAX_BPM = 1000

export type PoolQuery = {
  q: string
  bpmMin: number | null
  bpmMax: number | null
  halfDouble: boolean
  key: string | null
  harmonic: boolean
  tierMin: number | null
  uploader: string | null
  sort: PoolSort
}

export const EMPTY_QUERY: PoolQuery = {
  q: '', bpmMin: null, bpmMax: null, halfDouble: false,
  key: null, harmonic: false, tierMin: null, uploader: null, sort: DEFAULT_SORT,
}

export type PoolTrack = {
  file_id: string
  track_id: string | null
  uploaded_by: string
  uploader_name: string
  original_filename: string
  display_artist: string | null
  display_title: string
  container: string | null
  byte_size: number
  duration_ms: number | null
  bpm: number | null
  ibi_std_ms: number | null
  key_camelot: string | null
  key_open: string | null
  key_musical: string | null
  camelot_sort: number
  quality_tier: number | null
  lossy_ancestor: string | null
  meas_cutoff_hz: number | null
  integrated_lufs: number | null
  has_preview: boolean
  has_peaks: boolean
  created_at: string
  row_cursor: string
}

export type PoolResponse = { tracks: PoolTrack[]; nextCursor: string | null }

const numberIn = (raw: string | null, lo: number, hi: number): number | null => {
  if (raw === null || raw.trim() === '') return null
  const n = Number(raw)
  if (!Number.isFinite(n)) return null
  return Math.min(Math.max(n, lo), hi)
}

const flag = (raw: string | null): boolean => raw === '1' || raw === 'true'

/**
 * Total, never throws. A hand-edited or stale URL degrades to a weaker
 * filter rather than a 422 — pool_list() raises 22023 on an off-wheel key,
 * and that error has no business reaching a reader who clicked a bookmark.
 */
export function parsePoolQuery(sp: URLSearchParams): PoolQuery {
  const key = parseCamelot(sp.get('key'))
  const sortRaw = sp.get('sort')
  const uploader = sp.get('uploader')
  const tier = numberIn(sp.get('tier_min'), 1, 5)
  return {
    q: (sp.get('q') ?? '').trim().slice(0, MAX_Q_LENGTH),
    bpmMin: numberIn(sp.get('bpm_min'), 0, MAX_BPM),
    bpmMax: numberIn(sp.get('bpm_max'), 0, MAX_BPM),
    halfDouble: flag(sp.get('half_double')),
    key: key === null ? null : `${key.num}${key.letter}`,
    harmonic: flag(sp.get('harmonic')),
    tierMin: tier === null ? null : Math.round(tier),
    uploader: isUuid(uploader) ? uploader : null,
    sort: (POOL_SORTS as readonly string[]).includes(sortRaw ?? '')
      ? (sortRaw as PoolSort)
      : DEFAULT_SORT,
  }
}

/** Only non-default values are emitted, so the unfiltered pool has a clean URL. */
export function poolQueryToSearchParams(q: PoolQuery): URLSearchParams {
  const sp = new URLSearchParams()
  if (q.q !== '') sp.set('q', q.q)
  if (q.bpmMin !== null) sp.set('bpm_min', String(q.bpmMin))
  if (q.bpmMax !== null) sp.set('bpm_max', String(q.bpmMax))
  if (q.halfDouble) sp.set('half_double', '1')
  if (q.key !== null) sp.set('key', q.key)
  if (q.harmonic) sp.set('harmonic', '1')
  if (q.tierMin !== null) sp.set('tier_min', String(q.tierMin))
  if (q.uploader !== null) sp.set('uploader', q.uploader)
  if (q.sort !== DEFAULT_SORT) sp.set('sort', q.sort)
  return sp
}

/**
 * Sort order is not a filter: re-sorting an empty pool still shows an empty
 * pool, so `EmptyState` must say "nothing here yet" and not "no matches".
 */
export function isDefaultQuery(q: PoolQuery): boolean {
  return q.q === '' && q.bpmMin === null && q.bpmMax === null &&
    q.key === null && q.tierMin === null && q.uploader === null
}

export function poolListArgs(
  q: PoolQuery, cursor: string | null, limit: number,
): Record<string, unknown> {
  return {
    p_q: q.q === '' ? null : q.q,
    p_bpm_min: q.bpmMin,
    p_bpm_max: q.bpmMax,
    p_half_double: q.halfDouble,
    p_key: q.key,
    p_harmonic: q.harmonic,
    p_tier_min: q.tierMin,
    p_uploader: q.uploader,
    p_sort: q.sort,
    p_cursor: cursor,
    p_limit: limit,
  }
}
```

```ts
// src/pages/api/pool.ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import type { APIRoute } from 'astro'
import { dbErrorResponse, jsonError, rpcError } from '../../lib/upload-api'
import {
  PAGE_SIZE, parsePoolQuery, poolListArgs, type PoolTrack,
} from '../../lib/pool-api'

/**
 * The one list endpoint. Every filter is a query parameter and every filter
 * runs in Postgres — 2k rows is small enough for generous pages and far too
 * large to ship whole to a phone on a train.
 *
 * GET only, so Astro's CSRF origin check does not apply. Keep it that way;
 * the moment a mutation lands here it needs `content-type: application/json`
 * on every caller, curl included.
 */
export const GET: APIRoute = async ({ url, locals }) => {
  // Failures are JSON with an `error` key, always. src/lib/uploader.ts reads
  // a non-JSON body as "your session is gone", and the island in Task 6
  // follows the same rule.
  if (!locals.member) return jsonError(401, 'unauthenticated', 'sign in again')

  const query = parsePoolQuery(url.searchParams)
  const rawCursor = url.searchParams.get('cursor')
  const cursor = rawCursor !== null && rawCursor.length > 36 ? rawCursor : null

  try {
    const { data, error } = await locals.supabase.rpc(
      'pool_list', poolListArgs(query, cursor, PAGE_SIZE))
    if (error) return rpcError(error)

    const tracks = (data ?? []) as PoolTrack[]
    // A short page is the last page. Asking for one more row to find out
    // would double the work for the one case that does not matter.
    const nextCursor =
      tracks.length === PAGE_SIZE ? tracks[tracks.length - 1].row_cursor : null

    return Response.json({ tracks, nextCursor }, {
      // Member-scoped and cheap to recompute. Never let an intermediary
      // hand one member's pool to another.
      headers: { 'cache-control': 'private, no-store' },
    })
  } catch (e) {
    return dbErrorResponse(e instanceof Error ? e.message : String(e))
  }
}
```

```ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import { execSync } from 'node:child_process'
import { defineConfig } from 'astro/config'
import cloudflare from '@astrojs/cloudflare'
import solid from '@astrojs/solid-js'

/**
 * The deployed commit, resolved at build time. AGPL §13 obliges us to offer
 * the source of the *running* version, so a link to `main` is not enough —
 * it has to name a commit.
 *
 * Never throws: a build from a tarball has no .git, and a broken build is a
 * worse outcome than a vague source link.
 */
function buildSha(): string {
  const fromCi = process.env.WORKERS_CI_COMMIT_SHA
  if (fromCi) return fromCi
  try {
    const sha = execSync('git rev-parse HEAD', { encoding: 'utf8' }).trim()
    const dirty = execSync('git status --porcelain', { encoding: 'utf8' }).trim() !== ''
    return dirty ? `${sha}-dirty` : sha
  } catch {
    return 'unknown'
  }
}

export default defineConfig({
  output: 'server',
  adapter: cloudflare({ imageService: 'passthrough' }),
  integrations: [solid()],
  vite: {
    ssr: { external: ['node:buffer'] },
    // Textual substitution at build time, so the constant reaches both the
    // server bundle and any island that imports it, with no runtime cost
    // and no secret involved.
    define: {
      __BUILD_SHA__: JSON.stringify(buildSha()),
      __BUILD_TIME__: JSON.stringify(new Date().toISOString()),
    },
  },
})
```

```ts
// src/lib/build-info.ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

// Replaced textually by vite.define in astro.config.ts. Under Vitest they
// are simply absent, which is why every read is guarded — `typeof` on an
// undeclared identifier is legal JavaScript and yields 'undefined'.
declare const __BUILD_SHA__: string
declare const __BUILD_TIME__: string

export const REPO_URL = 'https://github.com/Ronitron007/localchune'

export const BUILD_SHA: string =
  typeof __BUILD_SHA__ === 'string' ? __BUILD_SHA__ : 'unknown'
export const BUILD_TIME: string =
  typeof __BUILD_TIME__ === 'string' ? __BUILD_TIME__ : ''

const isPinnable = (sha: string) => sha !== 'unknown' && !sha.endsWith('-dirty')

/** AGPL §13: the offer must be for the source of the version actually running. */
export function sourceUrl(sha: string = BUILD_SHA): string {
  return isPinnable(sha) ? `${REPO_URL}/tree/${sha}` : REPO_URL
}

export function shortSha(sha: string = BUILD_SHA): string {
  if (sha === 'unknown') return 'unknown'
  return sha.endsWith('-dirty')
    ? `${sha.slice(0, 7)}+`
    : sha.slice(0, 7)
}
```

```ts
// src/lib/debounce.ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

export type Debounced<A extends unknown[]> = ((...args: A) => void) & { cancel: () => void }

/**
 * Trailing-edge debounce. `cancel` exists so an island can drop a pending
 * search on cleanup — a timer that fires after the component is gone sets
 * state nothing is reading and, worse, issues a request nothing will use.
 */
export function debounce<A extends unknown[]>(
  fn: (...args: A) => void, ms: number,
): Debounced<A> {
  let timer: ReturnType<typeof setTimeout> | null = null
  const wrapped = (...args: A) => {
    if (timer !== null) clearTimeout(timer)
    timer = setTimeout(() => { timer = null; fn(...args) }, ms)
  }
  wrapped.cancel = () => {
    if (timer !== null) { clearTimeout(timer); timer = null }
  }
  return wrapped
}
```

```tsx
// src/components/TrackTable.tsx
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import { For, Show, createSignal, onCleanup, onMount } from 'solid-js'
import FilterBar, { type Uploader } from './FilterBar'
import EmptyState, { type EmptyVariant } from './EmptyState'
import StatusRegion from './StatusRegion'
import TrackRow from './TrackRow'
import {
  EMPTY_QUERY, isDefaultQuery, poolQueryToSearchParams,
  type PoolQuery, type PoolResponse, type PoolTrack,
} from '../lib/pool-api'

/**
 * THE table. Pool, crate view (M6), "my uploads" — all of them are this
 * component with different query parameters. A second table component is
 * drift (spec, cross-cutting rule 1).
 *
 * No virtualiser. A page is 100 rows and "load more" appends another 100;
 * a windowing library is a dependency, a scroll bug and a keyboard bug
 * bought to solve a problem that starts around 5,000 DOM rows.
 * TRIP-WIRE: if this ever renders more than 1,000 rows at once, revisit.
 */
export default function TrackTable(props: {
  initialTracks: PoolTrack[]
  initialCursor: string | null
  initialQuery: PoolQuery
  uploaders: Uploader[]
  poolEmpty: boolean
}) {
  // createSignal, not createStore: this component only ever REPLACES the
  // list or appends to it, never patches one row. UploadDropzone needs a
  // store because it patches rows by key; a store here would buy a
  // per-row proxy and the "is this argument a path or a value?" ambiguity
  // of setStore(array) for nothing.
  const [tracks, setTracks] = createSignal<PoolTrack[]>(props.initialTracks)
  const [query, setQuery] = createSignal<PoolQuery>(props.initialQuery)
  const [cursor, setCursor] = createSignal<string | null>(props.initialCursor)
  const [busy, setBusy] = createSignal(false)
  const [status, setStatus] = createSignal('')

  // One request in flight. A fast typist otherwise races two pages of
  // results into the same store and the loser wins.
  let inflight: AbortController | null = null

  const load = async (next: PoolQuery, from: string | null) => {
    inflight?.abort()
    const controller = new AbortController()
    inflight = controller
    setBusy(true)
    setStatus(from === null ? 'filtering…' : 'loading more…')

    const sp = poolQueryToSearchParams(next)
    if (from !== null) sp.set('cursor', from)

    try {
      const res = await fetch(`/api/pool?${sp.toString()}`, {
        headers: { accept: 'application/json' },
        signal: controller.signal,
      })
      // A non-JSON body means the session is gone and middleware redirected
      // us to /login — the same rule src/lib/uploader.ts follows.
      if (!(res.headers.get('content-type') ?? '').includes('application/json')) {
        setStatus('Your session ended. Reload the page to sign in again.')
        return
      }
      const body = (await res.json()) as PoolResponse & { error?: string; message?: string }
      if (!res.ok) {
        setStatus(body.message ?? body.error ?? `failed (${res.status})`)
        return
      }
      if (from === null) setTracks(body.tracks)
      else setTracks((prev) => [...prev, ...body.tracks])
      setCursor(body.nextCursor)
      setStatus('')
    } catch (err) {
      if (controller.signal.aborted) return
      setStatus(err instanceof Error ? err.message : String(err))
    } finally {
      if (inflight === controller) { inflight = null; setBusy(false) }
    }
  }

  const applyQuery = (next: PoolQuery) => {
    setQuery(next)
    // replaceState, NOT pushState: pushing one history entry per keystroke
    // group turns the back button into "undo my last filter", and the way
    // out of the pool becomes twenty presses long. The URL still updates,
    // so the view is still shareable and bookmarkable.
    const sp = poolQueryToSearchParams(next).toString()
    history.replaceState(null, '', sp === '' ? location.pathname : `?${sp}`)
    void load(next, null)
  }

  const loadMore = () => {
    const from = cursor()
    if (from === null || busy()) return
    void load(query(), from)
  }

  let sentinel: HTMLDivElement | undefined
  onMount(() => {
    // Progressive enhancement: the button below works without this. The
    // observer only saves a click.
    if (typeof IntersectionObserver === 'undefined' || sentinel === undefined) return
    const io = new IntersectionObserver(
      (entries) => { if (entries.some((e) => e.isIntersecting)) loadMore() },
      { rootMargin: '400px' },
    )
    io.observe(sentinel)
    onCleanup(() => io.disconnect())
  })

  const emptyVariant = (): EmptyVariant => {
    if (props.poolEmpty) return 'pool-empty'
    if (query().q !== '') return 'no-search-match'
    return 'no-filter-match'
  }

  return (
    <section class="tracktable">
      <FilterBar query={query()} uploaders={props.uploaders} onChange={applyQuery} />

      <p class="counts">
        <span>{tracks().length} track{tracks().length === 1 ? '' : 's'}</span>
        <Show when={cursor() !== null}><span> (more available)</span></Show>
        {' '}
        <StatusRegion message={status()} />
      </p>

      <Show
        when={tracks().length > 0}
        fallback={
          <EmptyState
            variant={emptyVariant()}
            term={query().q}
            onReset={isDefaultQuery(query())
              ? undefined
              : () => applyQuery({ ...EMPTY_QUERY, sort: query().sort })}
          />
        }
      >
        <table>
          <thead>
            <tr>
              <th scope="col"><span class="sr-only">Play</span></th>
              <th scope="col">Track</th>
              <th scope="col">BPM</th>
              <th scope="col">Key</th>
              <th scope="col">Length</th>
              <th scope="col">Quality</th>
              <th scope="col">Uploader</th>
              <th scope="col">Added</th>
            </tr>
          </thead>
          <tbody>
            <For each={tracks()}>{(track) => <TrackRow track={track} />}</For>
          </tbody>
        </table>
      </Show>

      <div ref={sentinel} />
      <Show when={cursor() !== null}>
        <button type="button" onClick={loadMore} disabled={busy()}>
          {busy() ? 'Loading…' : 'Load more'}
        </button>
      </Show>
    </section>
  )
}
```

- [ ] **Step 1: Teach the existing signer to sign a GET**

The signer, the credential handling and the URL construction all exist. Add a GET presigner beside `presignPut`; do **not** build a second `AwsClient`, and do not import `aws4fetch` anywhere else.

There is a trap here worth naming: `KEY_RE` matches `audio/<uid>/<file_id>.<ext>` only, and every derived artifact lives at `derived/<file_id>/<name>`. A GET signer that reused `objectUrl` would refuse every peaks JSON and every Opus preview with `BadKey`. The write path stays exactly as tight as it is; only the read path widens.

Append to `src/lib/r2.ts`:

```ts
/**
 * Derived artifacts: `derived/<file_id>/<name>`, written by the analysis
 * DO's R2 binding (workers/analysis/src/index.ts). Deliberately a SECOND
 * pattern rather than a looser first one — presignPut and the multipart
 * control plane must keep refusing anything that is not an upload key.
 */
const DERIVED_KEY_RE = /^derived\/[0-9a-f-]{36}\/[A-Za-z0-9._-]{1,64}$/

function urlFor(key: string, accept: (k: string) => boolean): string {
  if (!accept(key)) {
    throw new R2Error(`refusing to sign an implausible object key: ${key}`, 500, 'BadKey')
  }
  const { accountId, bucket } = conf()
  return `https://${accountId}.r2.cloudflarestorage.com/${bucket}/${key}`
}

/** Read path only. Accepts an upload key OR a derived-artifact key. */
export function readableObjectUrl(key: string): string {
  return urlFor(key, (k) => KEY_RE.test(k) || DERIVED_KEY_RE.test(k))
}

/**
 * One hour, matching PRESIGN_TTL_SECONDS, and for a related reason: the TTL
 * has to outlive the LISTENING SESSION, not the first request. Seeking in a
 * 15-minute track issues a fresh Range request against the same URL, so a
 * 15-minute TTL would make a scrub near the end of a long track fail with
 * an opaque media error.
 */
export const GET_TTL_SECONDS = 3600

export async function presignGet(
  key: string,
  opts: {
    ttlSeconds?: number
    contentDisposition?: string
    contentType?: string
    cacheControl?: string
  } = {},
): Promise<string> {
  const { accessKeyId, secretAccessKey } = conf()
  const url = new URL(readableObjectUrl(key))
  url.searchParams.set('X-Amz-Expires', String(opts.ttlSeconds ?? GET_TTL_SECONDS))
  // Response-header overrides are part of the SIGNED query string, so the
  // recipient cannot alter them — this is what makes it safe to put a
  // filename in a URL the browser will follow.
  if (opts.contentDisposition) {
    url.searchParams.set('response-content-disposition', opts.contentDisposition)
  }
  if (opts.contentType) url.searchParams.set('response-content-type', opts.contentType)
  if (opts.cacheControl) url.searchParams.set('response-cache-control', opts.cacheControl)

  const signed = await signer(accessKeyId, secretAccessKey)
    .sign(url.toString(), { method: 'GET', aws: { signQuery: true } })
  return signed.url
}
```

```ts
import type { APIRoute } from 'astro'
import { presignGet, r2ErrorResponse } from '../../../../lib/r2'
import { dbErrorResponse, isUuid, jsonError, rpcError } from '../../../../lib/upload-api'

const MIME: Record<string, string> = {
  mp3: 'audio/mpeg', flac: 'audio/flac', wav: 'audio/wav', wave: 'audio/wav',
  aiff: 'audio/aiff', aif: 'audio/aiff', aifc: 'audio/aiff',
  m4a: 'audio/mp4', mp4: 'audio/mp4',
  ogg: 'audio/ogg', oga: 'audio/ogg', opus: 'audio/ogg',
}

/**
 * Where to stream a track from. Returns a URL; the browser fetches R2
 * directly. Never proxy the bytes through here — R2's edge already answers
 * Range requests, which is what makes seeking free, and a Worker in the
 * path would turn $0 of egress into a bill and a 128 MB memory ceiling.
 *
 * Preview first: analysis emits a 128 kbps Opus preview (~5.5 MB for six
 * minutes) precisely because FLAC, WAV and AIFF are not broadly streamable
 * in a browser. When there is no preview — an mp3, or an M3 run that
 * predates the artifact-key columns — the original is served instead.
 */
export const GET: APIRoute = async ({ params, locals }) => {
  if (!locals.member) return jsonError(401, 'unauthenticated', 'sign in again')
  const id = params.id
  if (!isUuid(id)) return jsonError(400, 'bad_request', 'not a track id')

  let track: Record<string, string | null> | undefined
  try {
    const { data, error } = await locals.supabase.rpc('pool_get', { p_file_id: id })
    if (error) return rpcError(error)
    track = data?.[0]
  } catch (e) {
    return dbErrorResponse(e instanceof Error ? e.message : String(e))
  }
  // 404 covers both "no such file" and "not yours to see" — pool_get applies
  // the visibility rule, so an invisible track is indistinguishable from an
  // absent one, which is the point.
  if (!track) return jsonError(404, 'not_found', 'no such track')

  // Copied into a const before the guard: TypeScript does not narrow an
  // index-signature property access, so `track.r2_key` stays `string | null`
  // however many times it is checked.
  const r2Key = track.r2_key
  if (!r2Key) return jsonError(404, 'not_found', 'no such track')

  const preview = track.preview_key
  const key = preview ? `derived/${id}/${preview}` : r2Key
  const ext = (preview ?? r2Key).split('.').pop()?.toLowerCase() ?? ''

  try {
    const url = await presignGet(key, { contentType: MIME[ext] ?? 'application/octet-stream' })
    return Response.json({
      url,
      kind: preview ? 'preview' : 'original',
      mime: MIME[ext] ?? 'application/octet-stream',
    }, { headers: { 'cache-control': 'private, no-store' } })
  } catch (e) {
    return r2ErrorResponse(e)
  }
}
```

```ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import type { APIRoute } from 'astro'
import { presignGet, r2ErrorResponse } from '../../../../lib/r2'
import { dbErrorResponse, isUuid, jsonError, rpcError } from '../../../../lib/upload-api'

/**
 * Download serves the ORIGINAL, never the preview — the whole point of the
 * pool is that the file a DJ takes away is the file that was uploaded.
 *
 * A 302 rather than JSON, so a plain <a href> works with no JavaScript and
 * the browser's own download manager handles resume and progress.
 */
export const GET: APIRoute = async ({ params, locals }) => {
  if (!locals.member) return jsonError(401, 'unauthenticated', 'sign in again')
  const id = params.id
  if (!isUuid(id)) return jsonError(400, 'bad_request', 'not a track id')

  let track: Record<string, string | null> | undefined
  try {
    const { data, error } = await locals.supabase.rpc('pool_get', { p_file_id: id })
    if (error) return rpcError(error)
    track = data?.[0]
  } catch (e) {
    return dbErrorResponse(e instanceof Error ? e.message : String(e))
  }
  if (!track) return jsonError(404, 'not_found', 'no such track')
  // See source.ts: an index-signature access does not narrow, so copy first.
  const r2Key = track.r2_key
  if (!r2Key) return jsonError(404, 'not_found', 'no such track')

  const name = track.original_filename ?? 'track'
  // Two forms: a plain ASCII fallback for old clients and RFC 5987 for
  // everything else. The header value is inside the SIGNATURE, so nobody
  // can rewrite the filename by editing the URL.
  const ascii = name.replace(/[^\w.\- ]+/g, '_')
  const disposition =
    `attachment; filename="${ascii}"; filename*=UTF-8''${encodeURIComponent(name)}`

  try {
    const url = await presignGet(r2Key, { contentDisposition: disposition })
    return new Response(null, {
      status: 302,
      headers: { location: url, 'cache-control': 'private, no-store' },
    })
  } catch (e) {
    return r2ErrorResponse(e)
  }
}
```

```ts
// src/lib/peaks.ts
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

/**
 * The peaks JSON contract, and the pure half of the waveform renderer.
 *
 * CONTRACT (M3 must honour this): `{ version: 1, buckets: N, peaks: number[] }`
 * where `peaks` holds 2N interleaved min,max samples in [-1, 1]. A bare
 * array of 2N numbers is also accepted, because that is the cheapest thing
 * a DSP script emits and pinning the reader to one shape would make the
 * contract a coupling rather than an agreement.
 *
 * Everything here is pure: the canvas work in WaveformScrubber is a manual
 * check, this is not.
 */

export type Peaks = { buckets: number; values: Float32Array }
export type Bar = { min: number; max: number }

const clamp = (n: number) => (n < -1 ? -1 : n > 1 ? 1 : n)

export function parsePeaks(input: unknown): Peaks | null {
  const raw =
    Array.isArray(input) ? input
    : input !== null && typeof input === 'object' && Array.isArray((input as { peaks?: unknown }).peaks)
      ? ((input as { peaks: unknown[] }).peaks)
      : null
  if (raw === null || raw.length === 0 || raw.length % 2 !== 0) return null

  const values = new Float32Array(raw.length)
  for (let i = 0; i < raw.length; i++) {
    const n = raw[i]
    if (typeof n !== 'number' || !Number.isFinite(n)) return null
    values[i] = clamp(n)
  }
  return { buckets: raw.length / 2, values }
}

/**
 * Downsample to `width` bars by taking the EXTREME of each span, never the
 * mean. A mean waveform looks like a sausage and hides exactly the
 * transients a DJ is looking for when they scrub for the drop.
 */
export function peaksToBars(peaks: Peaks, width: number): Bar[] {
  const bars = Math.max(1, Math.min(Math.floor(width), peaks.buckets))
  const per = peaks.buckets / bars
  const out: Bar[] = []
  for (let b = 0; b < bars; b++) {
    const from = Math.floor(b * per)
    const to = Math.max(from + 1, Math.floor((b + 1) * per))
    let min = 1
    let max = -1
    for (let i = from; i < to && i < peaks.buckets; i++) {
      const lo = peaks.values[i * 2]
      const hi = peaks.values[i * 2 + 1]
      if (lo < min) min = lo
      if (hi > max) max = hi
    }
    out.push({ min, max })
  }
  return out
}

export function xToFraction(x: number, width: number): number {
  if (!Number.isFinite(width) || width <= 0) return 0
  const f = x / width
  return f < 0 ? 0 : f > 1 ? 1 : f
}
```

```ts
 * module-scope, so PlayButton (inside the TrackTable island) and PlayerBar
 * (its own island) share it without a parent — this works because Vite emits
 * one shared chunk for a module both islands import, which is why they must

 * tested under the node environment. That tests the machine, NOT playback.
 */

export type NowPlaying = {
  fileId: string
  artist: string

  durationMs: number | null
  hasPeaks: boolean
}

/** The slice of HTMLAudioElement this store uses, and nothing more. */
export type AudioLike = {
  src: string
  currentTime: number
  volume: number
  paused: boolean
  play(): Promise<void>
  pause(): void
  addEventListener(type: string, fn: () => void): void
  removeEventListener(type: string, fn: () => void): void
}

const [track, setTrack] = createSignal<NowPlaying | null>(null)
const [playing, setPlaying] = createSignal(false)
const [position, setPosition] = createSignal(0)
const [duration, setDuration] = createSignal(0)
const [volume, setVolumeSignal] = createSignal(1)
const [error, setError] = createSignal('')
const [loading, setLoading] = createSignal(false)

export const nowPlaying = track
export const isPlaying = playing
export const positionS = position
export const durationS = duration
export const playerVolume = volume
export const playerError = error
export const playerLoading = loading

let element: AudioLike | null = null
let makeAudio: () => AudioLike = () =>
  new Audio() as unknown as AudioLike

/** Test seam. Never called by application code. */
export function __setAudioFactory(factory: () => AudioLike): void {
  element = null
  makeAudio = factory
}

/** Test seam. Never called by application code. */
export function __resetPlayer(): void {
  element = null
  setTrack(null); setPlaying(false); setPosition(0)
  setDuration(0); setError(''); setLoading(false)
}

function audio(): AudioLike {
  if (element === null) {
    element = makeAudio()
    element.volume = volume()
    element.addEventListener('timeupdate', () => setPosition(element!.currentTime))
    element.addEventListener('loadedmetadata', () => {
      const d = (element as unknown as { duration?: number }).duration
      if (typeof d === 'number' && Number.isFinite(d) && d > 0) setDuration(d)
    })
    element.addEventListener('ended', () => { setPlaying(false); setPosition(0) })
    element.addEventListener('pause', () => setPlaying(false))
    element.addEventListener('play', () => setPlaying(true))
    element.addEventListener('error', () =>
      setError('That track would not play. Try downloading it instead.'))
  }
  return element
}

async function signedSource(fileId: string): Promise<string | null> {
  const res = await fetch(`/api/track/${fileId}/source`, {
    headers: { accept: 'application/json' },
  })
  // A non-JSON body means middleware redirected us to /login — the same
  // rule src/lib/uploader.ts and TrackTable follow.
  if (!(res.headers.get('content-type') ?? '').includes('application/json')) {
    setError('Your session ended. Reload the page to sign in again.')
    return null
  }
  const body = (await res.json()) as { url?: string; error?: string; message?: string }
  if (!res.ok || !body.url) {
    setError(body.message ?? body.error ?? `could not load that track (${res.status})`)
    return null
  }
  return body.url
}

export async function playTrack(next: NowPlaying): Promise<void> {
  setError('')
  if (track()?.fileId === next.fileId) {
    await togglePlay()
    return
  }
  setLoading(true)
  try {
    const url = await signedSource(next.fileId)
    if (url === null) { setPlaying(false); return }
    const el = audio()
    el.src = url
    el.currentTime = 0
    setTrack(next)
    setPosition(0)
    // Seed the duration from the row so the scrubber is usable before the
    // browser has decoded anything; loadedmetadata refines it.
    setDuration(next.durationMs === null ? 0 : next.durationMs / 1000)
    await el.play()
    setPlaying(true)
  } catch (e) {
    setError(e instanceof Error ? e.message : String(e))
    setPlaying(false)
  } finally {
    setLoading(false)
  }
}

export async function togglePlay(): Promise<void> {
  if (element === null || track() === null) return
  if (element.paused) {
    await element.play()
    setPlaying(true)
  } else {
    element.pause()
    setPlaying(false)
  }
}

export function seekToFraction(fraction: number): void {
  if (element === null || track() === null) return
  const total = duration()
  if (total <= 0) return
  const to = Math.min(Math.max(fraction, 0), 1) * total
  element.currentTime = to
  setPosition(to)
}

export function setVolume(v: number): void {
  const clamped = Math.min(Math.max(v, 0), 1)
  setVolumeSignal(clamped)
  if (element !== null) element.volume = clamped
}
```

```tsx
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import { createEffect, createSignal, onCleanup } from 'solid-js'
import { parsePeaks, peaksToBars, xToFraction, type Peaks } from '../lib/peaks'
import { durationS, nowPlaying, positionS, seekToFraction } from '../lib/player-store'

const WIDTH = 600
const HEIGHT = 48

/**
 * Canvas render of the peaks JSON, click and drag to seek.
 *
 * Two fetches deep on purpose: the API route signs a URL, the browser then
 * fetches R2 directly. The peaks object is immutable per file and carries a
 * one-year cache-control, so a second play is a memory-cache hit.
 *
 * The canvas drawing itself is verified by eye (Task 8) — the maths is in
 * src/lib/peaks.ts and is unit-tested there.
 */
export default function WaveformScrubber() {
  const [peaks, setPeaks] = createSignal<Peaks | null>(null)
  let canvas: HTMLCanvasElement | undefined

  createEffect(() => {
    const track = nowPlaying()
    setPeaks(null)
    if (!track || !track.hasPeaks) return
    const controller = new AbortController()
    onCleanup(() => controller.abort())

    void (async () => {
      try {
        const res = await fetch(`/api/track/${track.fileId}/peaks`, {
          headers: { accept: 'application/json' }, signal: controller.signal,
        })
        if (!res.ok) return          // 404 no_peaks is normal; draw flat
        const { url } = (await res.json()) as { url: string }
        const data = await fetch(url, { signal: controller.signal }).then((r) => r.json())
        setPeaks(parsePeaks(data))
      } catch {
        // A missing waveform is cosmetic. Never let it stop playback.
      }
    })()
  })

  createEffect(() => {
    const ctx = canvas?.getContext('2d')
    if (!ctx) return
    const p = peaks()
    const played = durationS() > 0 ? positionS() / durationS() : 0
    ctx.clearRect(0, 0, WIDTH, HEIGHT)
    const bars = p === null
      ? [{ min: -0.04, max: 0.04 }]                 // flat line, not an error
      : peaksToBars(p, WIDTH)
    const barWidth = WIDTH / bars.length
    for (let i = 0; i < bars.length; i++) {
      const mid = HEIGHT / 2
      const top = mid - bars[i].max * mid
      const bottom = mid - bars[i].min * mid
      ctx.fillStyle = i / bars.length <= played ? '#8ab4f8' : '#4a4a4a'
      ctx.fillRect(i * barWidth, top, Math.max(1, barWidth - 0.5), Math.max(1, bottom - top))
    }
  })

  const seek = (e: MouseEvent) => {
    if (!canvas) return
    const rect = canvas.getBoundingClientRect()
    seekToFraction(xToFraction(e.clientX - rect.left, rect.width))
  }

  return (
    <canvas
      ref={canvas}
      class="waveform"
      width={WIDTH}
      height={HEIGHT}
      role="slider"
      tabindex="0"
      aria-label="Seek"
      aria-valuemin={0}
      aria-valuemax={100}
      aria-valuenow={durationS() > 0 ? Math.round((positionS() / durationS()) * 100) : 0}
      onClick={seek}
      onKeyDown={(e) => {
        // Keyboard seeking, because a canvas is invisible to everything else.
        if (e.key === 'ArrowRight') seekToFraction((positionS() + 5) / Math.max(1, durationS()))
        if (e.key === 'ArrowLeft') seekToFraction((positionS() - 5) / Math.max(1, durationS()))
      }}
    />
  )
}
```

```sql
-- supabase/migrations/20260728120200_12_upload_status.sql
-- localchune — MIT licensed. See LICENSE.
-- NOTE: the distributed combination is AGPL-3.0 because the analysis
-- worker includes Essentia. LICENSE explains why.

-- ============================================================
-- What the uploader's own rows are doing right now.
--
-- An RPC rather than a PostgREST embed of files -> ingest_jobs, because the
-- embedded shape (object or array) depends on how PostgREST classifies the
-- relationship, and a client that guesses wrong fails at runtime with no
-- type error. One function, one shape, one round trip.
--
-- `terminal` is computed HERE so the browser's stop condition and the
-- database's idea of "finished" cannot drift. needs_review counts as
-- terminal ON PURPOSE: it waits for a human decision in M4, so polling it
-- forever would burn a request every five seconds for nothing.
-- ============================================================
create or replace function public.upload_batch_status(p_batch_id uuid)
returns table (
  file_id           uuid,
  original_filename text,
  byte_size         bigint,
  state             text,
  state_changed_at  timestamptz,
  reason            text,
  terminal          boolean
)
language plpgsql stable security definer set search_path = '' as $$
begin
  if not public.is_active_member() then
    raise exception 'forbidden' using errcode = '42501';
  end if;

  return query
  select f.id, f.original_filename, f.byte_size, f.state, f.state_changed_at,
         left(j.last_error, 500),
         f.state = any (array['stored','needs_review','rejected_duration',
                              'rejected_redundant','quarantined','failed','abandoned'])
    from public.files f
    left join public.ingest_jobs j on j.file_id = f.id
   -- Own rows only, whatever batch id is supplied. A batch belongs to one
   -- member, but relying on that would make a future shared batch a data
   -- leak instead of a feature.
   where f.batch_id = p_batch_id
     and f.uploaded_by = (select auth.uid())
   order by f.created_at, f.id;
end $$;

revoke execute on function public.upload_batch_status(uuid) from public, anon;
grant  execute on function public.upload_batch_status(uuid) to authenticated;
```

```ts
import type { APIRoute } from 'astro'
import { dbErrorResponse, isUuid, jsonError, rpcError } from '../../../lib/upload-api'
import type { FileStatus } from '../../../lib/upload-batch'

/**
 * Deliberately tiny: one RPC, the caller's own rows, no joins the browser
 * has to understand. Polled every five seconds while anything is still
 * moving, so it has to stay cheap.
 */
export const GET: APIRoute = async ({ url, locals }) => {
  if (!locals.member) return jsonError(401, 'unauthenticated', 'sign in again')
  const batchId = url.searchParams.get('batch_id')
  if (!isUuid(batchId)) return jsonError(400, 'bad_request', 'batch_id must be a uuid')

  try {
    const { data, error } = await locals.supabase.rpc(
      'upload_batch_status', { p_batch_id: batchId })
    if (error) return rpcError(error)
    const files = (data ?? []) as FileStatus[]
    return Response.json(
      { files, allTerminal: files.length > 0 && files.every((f) => f.terminal) },
      { headers: { 'cache-control': 'private, no-store' } },
    )
  } catch (e) {
    return dbErrorResponse(e instanceof Error ? e.message : String(e))
  }
}
```

```tsx
// src/components/FileStateTicker.tsx
// localchune — MIT licensed. See LICENSE.
// NOTE: the distributed combination is AGPL-3.0 because the analysis
// worker includes Essentia. LICENSE explains why.

import { For, Show, createEffect, createSignal, onCleanup } from 'solid-js'
import AnalysisFailedRow from './AnalysisFailedRow'
import StatusRegion from './StatusRegion'
import { currentBatchId, type FileStatus } from '../lib/upload-batch'

const POLL_MS = 5_000
/** Stop after twenty minutes. A stuck row is M3's cron's problem, not a
 *  reason to poll this member's browser until they close the tab. */
const MAX_POLL_MS = 20 * 60 * 1000

const LABEL: Record<string, string> = {
  pending: 'waiting',
  uploading: 'uploading',
  received: 'uploaded — queued for analysis',
  analysing: 'being listened to…',
  stored: 'ready',
  needs_review: 'held for review',
}

const FAILED = new Set([
  'failed', 'abandoned', 'quarantined', 'rejected_duration', 'rejected_redundant',
])

/**
 * The moment an upload visibly completes its journey: received → analysing
 * → stored, per file, without a page refresh.
 *
 * A degraded analysis (bpm 0, no beat found) still reaches `stored` and
 * still says "ready" — it is data, not an error. The em dash and the "no
 * beat detected" tooltip live in the pool table, where the number would be.
 */
export default function FileStateTicker() {
  const [files, setFiles] = createSignal<FileStatus[]>([])
  const [status, setStatus] = createSignal('')

  createEffect(() => {
    const batch = currentBatchId()
    setFiles([])
    if (batch === null) return

    let timer: ReturnType<typeof setTimeout> | null = null
    let stopped = false
    const startedAt = Date.now()
    const controller = new AbortController()

    const stop = () => {
      stopped = true
      if (timer !== null) clearTimeout(timer)
      controller.abort()
    }
    onCleanup(stop)

    const tick = async () => {
      if (stopped) return
      // Paused, not stopped: a backgrounded tab polling every five seconds
      // is a battery bug. visibilitychange below wakes it straight back up.
      if (typeof document !== 'undefined' && document.hidden) {
        timer = setTimeout(() => void tick(), POLL_MS)
        return
      }
      try {
        const res = await fetch(`/api/upload/status?batch_id=${batch}`, {
          headers: { accept: 'application/json' }, signal: controller.signal,
        })
        if (!(res.headers.get('content-type') ?? '').includes('application/json')) {
          setStatus('Your session ended. Reload the page to sign in again.')
          stop()
          return
        }
        const body = (await res.json()) as {
          files?: FileStatus[]; allTerminal?: boolean; error?: string; message?: string
        }
        if (!res.ok) {
          setStatus(body.message ?? body.error ?? `failed (${res.status})`)
          stop()
          return
        }
        setFiles(body.files ?? [])
        setStatus('')
        // The stop condition is the server's `terminal` flag, not a list of
        // state names copied into the browser — one place decides.
        if (body.allTerminal) return
        if (Date.now() - startedAt > MAX_POLL_MS) {
          setStatus('Still working. Reload this page to check again.')
          return
        }
        timer = setTimeout(() => void tick(), POLL_MS)
      } catch (err) {
        if (controller.signal.aborted) return
        setStatus(err instanceof Error ? err.message : String(err))
        timer = setTimeout(() => void tick(), POLL_MS)
      }
    }

    const wake = () => { if (!document.hidden && !stopped) void tick() }
    document.addEventListener('visibilitychange', wake)
    onCleanup(() => document.removeEventListener('visibilitychange', wake))

    void tick()
  })

  return (
    <Show when={files().length > 0}>
      <section class="ticker">
        <h2>Processing</h2>
        <StatusRegion message={status()} />
        <ul>
          <For each={files()}>{(f) => (
            <Show
              when={!FAILED.has(f.state)}
              fallback={
                <AnalysisFailedRow
                  name={f.original_filename} state={f.state} reason={f.reason}
                />
              }
            >
              <li class={`filerow ${f.state}`}>
                <span class="name">{f.original_filename}</span>
                <span class="state">{LABEL[f.state] ?? f.state}</span>
                <Show when={f.state === 'stored'}>
                  {' '}<a href={`/track/${f.file_id}`}>open</a>
                </Show>
              </li>
            </Show>
          )}</For>
        </ul>
      </section>
    </Show>
  )
}
```

```astro
  <FileStateTicker client:load />
```

## Done when

- A member opens `/` and sees every analysed track in the pool, server-rendered.
- Every filter runs in Postgres. No filtering happens in the browser, and the whole table is never shipped to it.
- A 174 bpm track is findable from an 86 bpm query with half/double on, and is not findable with it off — proven by test, not by eye.

- A degraded analysis renders `—` with a tooltip, everywhere, and never as an error.
- Every API failure is JSON with an `error` key. A dead session surfaces as a readable sentence, not as an HTML login page rendered into a table.

- The upload page shows a file moving `received → analysing → stored`, and stops polling when it arrives.

|---|---|---|
| Virtualised rows | 100-row pages over a ~2k pool. A windowing library is a scroll bug and a keyboard bug bought for nothing. Trip-wire at 1,000 rendered rows. | Only if the trip-wire trips |
| Genre facet | Needs a normalised vocabulary from the Discogs CC0 dumps (PRD §9.1). The component ships now and renders nothing. | M8 |
| Crates column, `AddToCrateMenu`, Crates nav link | Schema does not exist. Omit, do not disable. | M6 |
| Multi-file download menu | One track has one file until dedup lands. `DownloadButton` already takes an array. | M4 |
| Canonical artist/title, artwork, the Apple Music badge | `raw_tags` with a filename fallback until the catalogue match exists. | M7 |
| Format, year, label, "in my crates" and "added" date filters (PRD §9) | Year and label are empty or dirty in the source data the PRD measured; format and date add columns to the filter bar without adding much reach. | After the calibration pass |
| Full-text search (`pg_trgm`) | `ilike` over three columns on 2k rows is a sub-millisecond sequential scan. A trigram index is a real answer to a problem this pool does not have yet. | When the pool passes ~20k tracks |
| Position bookmark, play counts, cross-page player persistence | butternutcrack's `playerStore` has all three. Out of scope for the milestone that makes the pool usable. | v2 |
